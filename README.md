# 樱花之心

多色花瓣从零落的花毯中升起，汇聚成一颗有心跳、下缘翻卷的立体爱心。背景为艺术化的地中海海岸，带日出、日落与夜色变化。

页面默认无文字。右下角图标可以切换光线、花瓣混色、整颗爱心旋转，以及暂停和重新汇聚。

## 在线观看

GitHub Pages 启用后访问：https://slsily.github.io/sakura-heart/

## 启用 GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 /(root)，然后保存。此仓库为已构建的静态网站，无需安装依赖或运行构建。

## 离线观看

下载仓库后双击 index.html。Three.js 和所需纹理已打包，无需外部 CDN。

第三方资源及许可见 THIRD_PARTY_NOTICES.md。
